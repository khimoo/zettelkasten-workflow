このVaultのタスク管理ルール。ダッシュボードは [[Tasks]]。

## 目印の意味

| 目印 | 意味 | 表示される場所 |
|------|------|----------------|
| （無印） | 普通のタスク | [[Tasks]] の「まだおわってないやつ」 |
| 📅 期限あり | 締切タスク | 「今日まで」＋日次ノートの「今日中」 |
| ⏬ | **いつかやる棚**（時間があるとき用） | [[Tasks]] の「時間があるとき」だけ |
| `#daily` | 習慣（タスク管理の対象外） | 各日の日次ノートの「習慣」セクションだけ |
| `#proof_task` | 証明課題 | [[proof_task]] だけ |
| `#sentence_english` | 英文集め → **Anki移行中** | [[sentence_english_Anki移行]] 参照 |
| `[-]` | キャンセル（❌ 日付を添える） | どこにも出ない |
| `[/]` | 進行中 | 未完了扱い |

- **⏬の出し入れ**: ⏬を付ける＝棚に入る。やる気になったら⏬を外す（か📅を付けて⏬を外す）＝通常リストに復帰。
- **習慣（#daily）にはあえて📅を付けない**。サボっても期限切れが積み上がらず、記録は日次ノートに静かに残る。

## 見えない設定（data.json）

Tasksプラグイン設定は `.obsidian/plugins/obsidian-tasks-plugin/data.json`。**変更したらObsidian再起動が必要**。

- **globalQuery**（全クエリに自動適用される除外フィルタ）:
  `(NOT(tags include daily)) AND (NOT(tags include sentence_english)) AND (NOT(tags include proof_task)) AND (priority is above lowest)`
  → 「タスクが表示されない？」と思ったらまずこれを疑う。除外を無視したいクエリには `ignore global query` を書く。
- **useFilenameAsScheduledDate: true**（対象フォルダ: `Dailies` のみ）
  → 日次ノートに日付なしで書き捨てたタスクは、ファイル名の日付が暗黙の⏳scheduledになる。➕createdがあっても発動する。だから**日次ノートには気軽に書き捨ててよい**。その日を過ぎれば「締切りすぎてます」が拾ってくれる。

## タスクの置き場所

- 思いついたら**その日の日次ノートに書き捨てる**（↑の暗黙scheduledが効く）。
- テーマごとのリスト（例: [[卒業までにやりたいこと]]）は `Tasks/` 直下にノートを作ってよい。
- 終わったライフフェーズのリスト（就活など）は、未完了行を `[-]` ＋ ❌日付 にしてから `Tasks/archive/` へ移動。

## 注意

- Tasksプラグインは**Vault内の全チェックボックスをタスクとして拾う**。「要再調査」などノートの状態はチェックボックスでなくfrontmatterプロパティで表す（AI下書きは `ai_generated` → CLAUDE.md参照）。
- 日次ノートのクエリはテンプレート適用時に焼き込まれる。クエリを改善しても過去ノートには反映されない（globalQueryだけは実行時に全ノートへ効く）。
- 定期レビュー（週次・月次）は🔁タスクではなく、日次テンプレートのdataviewjsがリマインドする（月曜/月初のDailyに📋案内、未実施の間はその週/月のDailyに⚠️が出続ける。済/未済は `Reviews/` に該当ノートが存在するかで判定）。🔁は完了チェック直後に次回分が生成されて毎日のリストに居座るため廃止した。

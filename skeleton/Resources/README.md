# Resources — 実務リファレンスの棚

Zettel（思考ノート）ではない、**実務の参照情報**を置く場所。
住居の契約、学校の履修・単位、家電の説明書など「必要なとき正確に引く事実」を管理する。

## この棚のルール

- **Zettelkasten方法論の対象外**。zettel化しない。StructureNote に接続しない。
- **タグを付けない**（object tag も付けない）。
- **wikilink で思考ネットワークに接続しない**（Resources 内での相互リンクは可）。
- **チェックボックス `- [ ]` を使わない**。Tasks プラグインが Vault 全体から拾い、タスク一覧を汚染するため。
- 更新される数値・日付（残り単位数・契約更新日・型番など）は本文に散らさず **frontmatter に構造化**する。
- 原本（契約書PDF・説明書スキャン・写真）はノートから `![[...]]` で埋め込む。
- 検索から隠さない（素早く引くのが目的。Obsidian の Excluded files には入れない）。

## 構造

```
Resources/
  住居/    住居契約・更新・設備・連絡先など
  学校/    履修・単位計算・卒業要件など
  家電/    型番・エラーコード・手入れ・保証など
```

ドメインが増えたらフォルダを足す。1つの対象 = 1枚のノートを基本とする。

## frontmatter の目安

```yaml
---
種別: 住居契約        # 住居契約 / 単位 / 家電 など
最終確認: 2026-07-31  # この情報を最後に確認・更新した日
# 以下は種別に応じて追加する例
更新日: 2027-03-31    # 契約更新期限など
型番: ""              # 家電の型番
---
```
